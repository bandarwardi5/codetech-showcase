# CodeTech Showcase

Create a premium modern Arabic RTL website for an Egyptian software company called CodeTech.

The website should look like a real professional software agency, not AI-generated. Use realistic professional photography, software screenshots, office/team images, and image-based backgrounds instead of abstract AI illustrations.

Include:

Sticky navbar

Hero section with large photographic background

Services: websites, web apps, mobile apps, custom software, e-commerce, dashboards

Featured projects / portfolio

Why CodeTech

Work process

Technologies

Client testimonials

FAQ

Strong final CTA

Professional footer

Arabic RTL typography using Cairo or IBM Plex Sans Arabic.

Visual style: premium, clean, corporate, sophisticated, with dark navy, white and blue tones. Use large images, generous whitespace, editorial layouts and realistic UI mockups.

Add subtle professional animations: scroll reveal, parallax images, hover effects, counters and smooth transitions. Avoid excessive gradients, glassmorphism, glowing effects, 3D blobs, generic icons and repetitive rounded cards.

The final result should communicate trust, technical expertise, quality and professionalism and feel suitable for an established Egyptian/MENA software company.
